# Glossary

## Status: pending domain definition

This repository is an application template and does not yet define a product
domain. No domain terms have been accepted for this glossary.

When product work introduces a term that is business-specific, ambiguous, or
easy to use inconsistently, add it here with its agreed meaning and any terms
that must not be used as synonyms. Record hard-to-reverse terminology decisions
in `docs/adr/`.

See [docs/agents/domain.md](docs/agents/domain.md) for the single-context
documentation workflow and [DER.md](DER.md) for the pending product
persistence model and the existing technical Firebase stores.

Do not add framework or implementation terms (for example, Next.js, React, or
component) unless the project assigns them a domain-specific meaning.

Upstream UI terms and primitive-family differences are indexed in
[the shadcn/ui rules](.agents/rules/shadcn.md#shadcnui-maintenance). Keep those technical details
in the design, coding, and tooling guides; a documentation refresh does not
resolve this glossary's pending product terminology.

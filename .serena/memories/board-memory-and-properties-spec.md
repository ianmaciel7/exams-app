# Regra de Memória no Board e Redesenho de Propriedades

## 1. Regra Mandatória de Preservação no Board
Todas as informações, fotos, evidências, descobertas, decisões visuais e memórias levantadas durante o trabalho no projeto Exam App DEVEM ser guardadas no board (`prototypes/board-exam-app/board.json` / `BOARD.md` e pasta `assets/`). Qualquer informação importante DEVE ser registrada e persistida no board.

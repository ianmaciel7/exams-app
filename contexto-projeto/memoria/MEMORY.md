# Exams App
- Objetivo: criar do zero um app de estudos para concursos e certificações (questões, simulados, revisão espaçada, leitura de PDFs, organização do conhecimento).
- Ordem: planejamento, pesquisa, requisitos, arquitetura da informação, fluxos, UX/UI, design system e protótipo antes de codar.
- Referências (sem copiar interfaces): ExamTopics, QConcursos, Crucial Exams, Capacities, Linear, Readwise Reader.
- Decisões baseadas em documentação oficial e princípios de UX/UI; acessibilidade e responsividade obrigatórias.
- Projeto anterior é só referência de aprendizado. Estrutura limpa, modular, documentada; evitar complexidade e retrabalho.
- Usuário escreve em português.
- Repos de referência (projetos antigos/templates): exams-app-antigo-2, exams-app-old, shadcn-firebase-template, shadcn-template, notes-app (todos ianmaciel7).

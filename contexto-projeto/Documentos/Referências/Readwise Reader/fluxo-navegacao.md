# Fluxo de navegação (páginas públicas)

Mapa das páginas públicas lidas. Setas com a ação que leva de uma página à outra.

```
[Home /read] --"Get started for free"--> [Cadastro / Sign up]
[Home /read] --link de preços (Inferência, não confirmado)--> [Preços /pricing]
[Preços] --"Start 30 day free trial"---> [Cadastro]
[Preços] --"See all Reader features"---> [Página de recursos]  (não capturada)
[Home] --"Sign in"---------------------> [Login]  (exige conta)
[Login/Cadastro] --------------------> [Biblioteca do app]  (não visto)
[Docs /reader/guides] --"Filtering / Ghostreader / Workflows"--> [Subseções de guias]
[Changelog] --------------------------> [Novidades do produto]
```

- **Confirmado**: Home → Preços; Preços → cadastro (texto do botão); Home → cadastro (botão "Get started for free"); Docs → índice de seções.
- **Inferência**: caminho exato de login até a biblioteca; subseções de guias (URLs não abertas).
- **Não verificado**: biblioteca, leitor, grifos, Ghostreader dentro do app (exige login).

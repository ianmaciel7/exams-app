Empty states explain why a list or view is empty and offer one clear next step, for example "No notes yet" or "No questions match these filters". Centered block, 48px padding, a 48px line illustration or icon in `muted`, display-sm serif title in `ink`, one or two lines of body-sm in `muted`, and one primary button. The container is `surface-soft` with a hairline border.

**Variants.** First use (invites creation), no results (suggests clearing filters), and error (use Banner for the failure and EmptyState only when there is nothing to show). Copy is plain and positive, no exclamation marks.

**Accessibility.** The title is a heading at the right level; the action is a real button; decorative art is `aria-hidden`.

**Consumer provides** the icon, copy and action.

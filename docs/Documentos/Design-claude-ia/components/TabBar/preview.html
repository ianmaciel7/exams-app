Claro

Clique numa aba e use Alt + T, Alt + W, Alt + 1 a 9, Alt + Shift + setas, Shift + P, setas, Home e End. Arraste para reordenar. Botão direito abre o menu da aba.

Largura estreita: as abas que não cabem vão para o menu de excesso, pesquisável.

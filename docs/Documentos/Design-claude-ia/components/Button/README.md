Buttons trigger the primary action on a page: coral for the one main CTA, hairline for secondary. Height 40px, radius 8px, label 14px/500. Pressed state uses primary-active; nothing else changes on hover. On dark surfaces the secondary button uses surface-dark-elevated and never inverts to light. Icon buttons are 36px circles. The consumer provides labels and click handlers.


**Ink variant:** inside the app (study screens, modals, question cards) the main action uses an ink button (background ink, label canvas), matching the other app components. Coral stays for marketing/landing CTAs and the single highlight on a page.

# ADR 0003: create-next-app

## Status
Accepted

## Date
2026-11-10

## Context
The project requires a modern web framework to host the application. To ensure long-term maintainability, community alignment, and zero custom boilerplate, the application should be initialized using the official Next.js CLI (`create-next-app`).

This ADR governs the initial scaffolding generated by the CLI.

## Decision

We initialize the Next.js application in the repository root using the official Next.js CLI with non-interactive flags:

```bash
pnpm create next-app . --ts --app --src-dir --react-compiler --biome --tailwind --agents-md --use-pnpm
```

### Scaffolding Invariants:
1. **TypeScript (`--ts`)**: Standard `tsconfig.json` with strict type checking enabled.
2. **App Router (`--app`)**: Next.js App Router architecture rather than the legacy Pages Router.
3. **Source Directory (`--src-dir`)**: Application source code organized under `src/app/` to keep root clean.
4. **React Compiler (`--react-compiler`)**: Native integration with the React Compiler for automated memoization.
5. **Biome (`--biome`)**: Official Next.js CLI integration for formatting and linting via `@biomejs/biome` (`biome.json`), replacing ESLint.
6. **Tailwind CSS (`--tailwind`)**: Tailwind CSS v4 styling setup with `@tailwindcss/turbopack`.
7. **Agent Rules Integration (`--agents-md`)**:
   - Emits the official Next.js agent rules block (`<!-- BEGIN:nextjs-agent-rules --> ... <!-- END:nextjs-agent-rules -->`) into `AGENTS.md`.
8. **Base Dependencies**:
   - `next`: Latest stable release (v16).
   - `react` & `react-dom`: React 19.
   - Core dev dependencies: `typescript`, `@types/node`, `@types/react`, `@types/react-dom`, `@biomejs/biome`, `tailwindcss`, `@tailwindcss/turbopack`, `babel-plugin-react-compiler`.
9. **Next.js 16 Runtime & Compiler Flags (`next.config.ts`)**:
   - `reactCompiler: true`: Activates automated fine-grained memoization.
   - `cacheComponents: true` & `partialPrefetching: true`: Enables Partial Prerendering (PPR) and component-level caching primitives.
   - `turbopack`: Explicit rule configuring `@tailwindcss/turbopack` as CSS loader.

## Consequences

- **Positive**:
   - Reproducible foundation generated directly by the official framework toolchain.
   - Standardized directory layout (`src/app/layout.tsx`, `src/app/page.tsx`).
   - Version-matched documentation bundled directly at `node_modules/next/dist/docs/` accessible offline, preventing hallucination of outdated APIs.
   - No hand-crafted boilerplate or manual configuration required for initial startup.
- **Negative / Operational**:
  - The default scaffolding produces baseline configuration files that may require future project-specific tuning.

# Referência Anki (visão geral)

Objetivo: entender como o Anki organiza estudo com repetição espaçada, para apoiar as decisões do Exams App. Não copiamos interface nem conteúdo: é material interno de referência.

Legenda: **Confirmado** = lido na documentação oficial ou visto na captura (fonte indicada). **Inferência** = dedução minha, não citação. **Não verificado** = não consegui ler a fonte nesta etapa.

## Fontes consultadas
- Manual oficial (docs.ankiweb.net), páginas lidas: `manual/getting-started` (conceitos), `manual/studying` (estudo e botões), `manual/deck-options` (opções, FSRS). Leitura por trechos: o conteúdo completo tem muito texto de navegação.
- Página pública apps.ankiweb.net (captura de tela).
- Não lidas nesta etapa: `manual/syncing`, `manual/stats`, `manual/addons`, `manual/editing`, `manual/templates/*`. A página `docs.ankiweb.net/sync.html` retornou 404 (o caminho correto é `/manual/syncing`, que não foi lido). Ficam como pendência.

## Índice dos arquivos
1. [funcionalidades.md](funcionalidades.md): decks, notas, cartas, tipos de nota, agendamento, botões, estatísticas, sincronização, complementos.
2. [jornada.md](jornada.md): criar deck, adicionar nota, estudar, avaliar, ver estatísticas.
3. [algoritmo-repeticao.md](algoritmo-repeticao.md): repetição espaçada explicada de forma simples (SM-2 e FSRS).
4. [inventario-telas.md](inventario-telas.md): telas e componentes confirmados pela documentação e pelas capturas.
5. [o-que-aprender.md](o-que-aprender.md): o que vale levar para o Exams App.

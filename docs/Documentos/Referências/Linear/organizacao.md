# Linear — Organização da informação
Workspace > Team (workflow, cycles, labels) > Issue (status, assignee, prioridade, projeto, cycle, labels, estimate). Project > Milestone. Initiative > Projects (pode ter sub-initiatives). Teams podem ter sub-teams (herdam workflow/cycles/labels). Views salvas filtram o mesmo dado.
Fonte: https://linear.app/docs/conceptual-model (Confirmado).
DER do quadro: Inferência (Linear não publica esquema de dados); montado a partir do modelo conceitual.

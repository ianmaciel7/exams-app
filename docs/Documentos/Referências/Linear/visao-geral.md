# Linear — Visão geral
Fonte: https://linear.app/docs · https://linear.app/ (consultadas em 19/11/2026)

- **O que é (Confirmado):** "o sistema de desenvolvimento de produto para equipes e agentes" (home). Docs: Start Guide, Concepts, Projects, Initiatives, Triage, Search, Inbox, Display options, GitHub, Slack, MCP, Linear Agent.
- **Unidade de trabalho (Confirmado):** Issue. Pertence a um Team e percorre o workflow do time (statuses ordenados).
- **Hierarquia (Confirmado, docs/conceptual-model):** Workspace > Teams > Issues; Projects (com Milestones) agrupam issues; Initiatives agrupam projects; Cycles = período repetido do time; Views = formas de olhar o mesmo trabalho.
- **Interface (Confirmado, home):** sidebar à esquerda (Pulse, Inbox, My issues, Reviews; Workspace: Initiatives, Projects, More; Favorites), área principal com issue aberta e painel de propriedades à direita, tema escuro.
- **Interesse para o Exams App:** navegação por teclado, command menu, listas densas, agrupar/ordenar sem mudar o dado, inbox, design sóbrio. Não copiar a interface.
- **Não verificado:** workspace real logado (login exigido; demo /demo não carregou no tempo limite).

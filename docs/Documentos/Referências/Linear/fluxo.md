# Linear — Fluxo principal
Confirmado nos docs: criar workspace (linear.app/signup, e-mail de trabalho) > criar/importar issues > triar (Triage) > atribuir, priorizar, mover pelo workflow > planejar em Cycle > agrupar em Project/Initiative > acompanhar por Views.
Navegação: `G` depois `I` abre Inbox; `/` abre busca; `O` depois `I` abre issues recentes; Shift+V abre display options; Cmd/Ctrl+B alterna lista/board.
Inferência: o fluxo diário é Inbox > My issues > abrir issue > mudar propriedade por atalho > próxima (setas/J/K).

# Linear — Matriz de interações (Confirmado em docs)
| Ação | Teclado | Mouse/menu |
|---|---|---|
| Buscar no workspace | `/` | ícone de lupa na sidebar |
| Buscar na view atual | Cmd/Ctrl+F | campo no topo direito |
| Issues recentes / busca rápida | `O` depois `I` | ícone de relógio |
| Prefixos no command menu | `i`+espaço issues, `p` projetos, `u` usuários, `t` times, `l` labels, `f` favoritos, `d` documentos | — |
| Ir ao Inbox | `G` depois `I` | sidebar |
| Navegar lista | `J`/`K` ou setas | clique |
| Snooze / lembrete | `H` | clique direito > Snooze |
| Marcar lido | `U` | menu |
| Display options | Shift+V | botão topo direito |
| Lista/board | Cmd/Ctrl+B | Display options |
Filtros: digitar `@` na busca cria filtro por pessoa/time/status.

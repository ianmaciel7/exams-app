# Referência: Readwise Reader

Referência interna para o Exams App (app de estudos para concursos e certificações, com leitura de PDFs, grifos e anotações). Não copia interface nem conteúdo do produto.

**Escopo e limites**
- Só páginas públicas: site de marketing (readwise.io/read), preços, guias de documentação (docs.readwise.io/reader) e changelog. Nenhum login, nenhum captcha, poucas requisições.
- O app (biblioteca, leitor, grifos, Ghostreader) exige conta. Não foi visto diretamente. Tudo que descreve o app vem de texto público e está marcado como **Inferência**.
- Páginas de documentação individuais de grifos, atalhos e Ghostreader retornaram 404 nos caminhos testados. O índice de guias foi lido; o conteúdo interno de cada guia não foi aberto.

**Legenda**
- **Confirmado**: lido em página pública, com a fonte indicada.
- **Inferência**: decisão ou dedução minha, sem confirmação no produto.

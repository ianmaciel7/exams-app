# Question Component Study — v0.1.0

This editable board preserves the detailed question studies previously adjacent to the [Sketch](../../sketch/). It is a working exploration, not a screen, a prototype, a required release stage, or an approved specification. Its controls, example data, behaviors and implementation details remain proposals or historical reference unless the [release decision record](../../product.md) explicitly confirms them.

The nine existing groups cover question anatomy, control taxonomy, answer states, content variants, resource drawers, triggers and consequences, feedback, component states, and interaction proposals. Interaction examples stay on this board instead of becoming a second source of approved requirements. Some examples include historical source text; verify provenance and rules before using them.

The [migration mapping](../question-migration.json) records the original and destination IDs and ordering. All 635 moved elements were preserved byte for byte, and the original sketch retains 100 elements. This board needs visual and usability review.

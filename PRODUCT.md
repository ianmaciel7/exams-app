## Product purpose

Exam App is an exam preparation project.

## Current release

v0.1.0 — current direction: select a competition in the sidebar and browse its questions in a vertically scrollable, paginated list. The owner also requested correct and incorrect answer states. The owner approved explicit answer submission: select an option, then activate Answer to evaluate it. An incorrect response marks the selected option and reveals the correct one. Page changes reset the question list to the top. A load failure offers a manual Retry action. These are release decisions, not verified implementation. Other capabilities, platform, stack, target users and constraints remain undefined. Previous features and decisions are historical candidates, not requirements.

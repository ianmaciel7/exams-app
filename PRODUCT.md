# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

Developers, technical founders, and product engineering teams building modern production web applications and SaaS products. They need a robust, production-ready foundation with zero setup friction, high-accessibility UI, and enterprise-grade authentication.

## Product Purpose

Provide a complete, production-grade web application template combining Next.js 16 App Router, Firebase, and shadcn/ui (Base UI) with verified engineering standards, strict accessibility compliance, and thorough test coverage.

## Positioning

Unlike basic starter boilerplates that offer only minimal authentication and placeholder styling, this template delivers a hardened, production-ready foundation: multi-provider OAuth, multi-factor authentication (SMS and TOTP), role-based session control, fluent trilingual internationalization (en, es, pt-BR), and accessible compound UI components out of the box.

## Core Capabilities

- **Frictionless & Multi-Factor Auth:** Email/password and OAuth (Google, GitHub, Microsoft, Apple, Twitter, Yahoo) combined with SMS and TOTP MFA flows.
- **Enterprise-Grade UI Components:** shadcn/ui built on Base UI (`base-nova`) with strict keyboard navigation, touch targets, and ARIA compliance.
- **Trilingual Internationalization:** Complete localization support for English, Spanish, and Brazilian Portuguese with `next-intl`.
- **Role-Based Access Control & Profile Management:** Protected routes and session bridging for secure user operations.

## Constraints & Standards

- **Platform:** Responsive web across mobile, tablet, and desktop viewports.
- **Visual Design:** Governed by `DESIGN.md` (neutral palette, 0.625rem radius, Geist typography).
- **Engineering Standards:** Governed by `CODING_STANDARDS.md` and repository integrity checks (`verify:fast`, `verify:static`).

# Exam App Open Artifact access

Read AGENTS.md and docs/agent-access.md first. Run the pinned installer if necessary, then the official doctor for your harness. Read the official entry skill and the relevant type skill in the resolved runtime (vendor/artifact-types/<type>/SKILL.md). Inspect docs/releases/v0.1.0/current-state.json and the owning board meta before opening or editing. Use the existing board folder, not a new artifact. Native tool availability, ownership, and permission must be verified before claiming collaboration. Use the official plugin as the interactive integration; never enable the isolated MCP fallback at the same time. Run `node scripts/open-artifact-library.mjs catalog` for canonical paths and `status` for the native library mapping. Registration (`register --apply`) is an owner-operated command, never an agent action. For the standalone viewer use node scripts/open-boards.mjs; for full Shell collaboration use the native library and confirm the root and owner. Native IDs are not preview IDs; use the native library to navigate. Static Pages cannot send requests to agents or persist changes. Never publish private comments or open an unapproved remote. Prefer scoped file or native CLI reads if MCP is unavailable; disclose missing capabilities. Run structural checks and relevant independent visual checks after edits.
